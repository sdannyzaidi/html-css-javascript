### Module 3 — Bootstrap

A responsive restaurant website built using Bootstrap.

### Module 4 — JavaScript

A small JavaScript application demonstrating the module pattern and basic JavaScript concepts.

**Topics:** JavaScript ES5, IIFE, module pattern, arrays, functions

[View Project](./module4-solution/index.html)

A restaurant website that loads menu data dynamically using AJAX.

[View Project](./module5-solution/index.html)

## Running the Projects

The projects are standalone web pages. Open the corresponding `index.html` file in a browser.

```text
module2-solution/index.html
module3-solution/index.html
module4-solution/index.html
module5-solution/index.html
```

For Module 4, check the browser console to see the output.
